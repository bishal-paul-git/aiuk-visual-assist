# Delivery Roadmap

# Phase 0 — Product Definition
Deliverables:
- PRD
- architecture
- UX
- data model
- security model
- roadmap
- acceptance criteria

# Phase 1 — Full Visual Product
Goal:
Design and build the complete navigable product experience.

Deliver:
- customer experience
- human console
- admin portal
- workflows
- policies
- analytics
- cost
- audit
- health

No production APIs required.

# Phase 2 — Technical POC
Goal:
Prove one complete interaction.

Recommended use case:
Router support.

Deliver:
- real browser session
- live voice
- selected frame capture
- multimodal reasoning
- one controlled workflow
- basic human escalation
- basic logging

# Phase 3 — Internal Alpha
Deliver:
- session orchestrator
- stronger state model
- visual observation schema
- audit
- QA tooling
- system monitoring

# Phase 4 — Client Pilot
Deliver:
- one real client
- production-like authentication
- business integration
- client policy
- reporting
- support process
- privacy controls

# Phase 5 — Production Pilot
Deliver:
- hardened tenancy
- RBAC
- retention
- alerts
- resilience
- incident process
- cost attribution
- production monitoring

# Phase 6 — Enterprise Product
Deliver:
- SSO
- enterprise audit
- regional deployment
- stronger governance
- workflow versioning
- enterprise analytics
- SLA
- client self-service administration

# Phase 7 — Scale
Deliver:
- more sectors
- reusable workflow templates
- partner integrations
- advanced visual event detection
- optional AI copilot during human sessions
