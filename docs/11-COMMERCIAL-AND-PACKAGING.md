# Commercial and Packaging Model

# 1. Product Category

Human + AI Visual Assistance Platform

# 2. Core Commercial Value

Potential customer value:
- higher first-contact resolution
- shorter support interactions
- fewer unnecessary field visits
- better evidence capture
- reduced repeat contacts
- faster human diagnosis
- improved support quality

# 3. Commercial Components

## Implementation
Charge for:
- discovery
- workflow design
- configuration
- integration
- testing
- rollout

## Platform Fee
Charge for:
- tenant
- portal
- analytics
- QA
- workflow management
- admin
- monitoring

## Usage
Possible pricing:
- per session
- per minute
- per successful resolution
- bundled usage

## Enterprise Add-ons
- SSO
- dedicated environment
- custom residency
- enhanced support
- SLA
- advanced analytics
- custom integrations

# 4. Pricing Principle

Do not price only from infrastructure cost.

Price should reflect:
- field visit avoided
- handling time saved
- resolution improvement
- operational risk reduced
- support capacity increased
