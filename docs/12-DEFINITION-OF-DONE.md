# Definition of Done

# 1. Visual Product Complete

The visual product is complete when:
- all primary routes exist
- customer journey is complete
- human console is complete
- admin portal is complete
- workflows are understandable
- escalation is visible
- analytics, cost, audit and health are present
- responsive behaviour is acceptable

# 2. Technical POC Complete

The technical POC is complete when:
- a customer can start a real session
- voice works
- selected visual evidence is captured
- AI can interpret selected evidence
- workflow advances correctly
- uncertainty is handled
- human escalation works
- session ends cleanly
- audit events are recorded
- latency and cost are measured

# 3. Client Pilot Complete

The pilot is complete when:
- client-specific workflow is configured
- client acceptance criteria pass
- security review is complete
- privacy requirements are addressed
- monitoring exists
- incident process exists
- production support ownership is agreed

# 4. Enterprise Release Complete

Enterprise release requires:
- tenancy controls
- SSO/RBAC where required
- audit
- retention
- security hardening
- monitoring
- operational runbooks
- cost attribution
- QA process
- versioning
- rollback
- documented SLA/support model
