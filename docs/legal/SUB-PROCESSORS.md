# Sub-processors

> Draft. Check each provider's current terms before signing a client contract. Absolute Intelligence UK Ltd is the processor and these are its sub-processors. Give clients notice before adding one.

| Provider | What it does | Data it handles | Where | Safeguard |
|---|---|---|---|---|
| Anthropic | AI that reads still pictures and the conversation | Still frames, transcript text | USA | Provider DPA; UK IDTA or UK–US data bridge; no training on API data under its commercial terms |
| ElevenLabs | Assistant voice; speech to text | Assistant replies (text), customer speech audio (when speech-to-text is on) | USA / EU | Provider DPA; UK IDTA |
| Deepgram (optional) | Speech to text | Customer speech audio | USA | Provider DPA; UK IDTA |
| Render | Hosts the server | All session data in transit and in memory | USA (Oregon) today; Frankfurt planned | Provider DPA; UK IDTA |
| Supabase | Database | Stored sessions, photos, transcripts, audit | EU (Frankfurt) | Provider DPA |
| Twilio | Text message links; live video relay | Customer phone number; encrypted video relay | USA / global | Provider DPA; UK IDTA |
| Resend | Email links | Customer email address | USA | Provider DPA; UK IDTA |
| GitHub | Code, automated checks, encrypted nightly database backup (30 days) | Encrypted backup file only | USA | Provider DPA; UK IDTA; backup encrypted with a key GitHub does not hold |
