# Operations and Support

# 1. Operational Ownership

Recommended ownership areas:
- Platform operations
- AI quality
- Real-time media
- Client integrations
- Security
- Customer support
- Incident management

---

# 2. Monitoring

Monitor:
- active sessions
- media quality
- speech latency
- visual inference latency
- workflow failures
- escalation queue
- provider health
- cost
- session failures
- model errors

---

# 3. Incident Severity

Example:
- P0: widespread production outage or unsafe behaviour
- P1: major client impact
- P2: degraded feature
- P3: minor issue

---

# 4. Runbooks

Create runbooks for:
- media outage
- voice outage
- model outage
- workflow outage
- human queue outage
- database issue
- high latency
- cost anomaly
- incorrect AI behaviour

---

# 5. Change Management

Version:
- workflows
- policies
- prompts
- models
- integrations

Production changes should be traceable and reversible where practical.
